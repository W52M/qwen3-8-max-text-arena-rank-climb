# Text Arena Rank Climb

A vertical Remotion animation showing Alibaba Qwen3.8 Max rapidly climbing the Text Arena leaderboard and landing at rank 2.

## Specs

- 1080 × 1920
- 30 fps
- 8 seconds
- Composition: `TextArenaRankClimb`

## Run

```bash
npm ci
npm run studio
```

## Render

```bash
npm run render
```

The rendered video is written to `out/text-arena-rank-climb.mp4` and is intentionally excluded from Git.
